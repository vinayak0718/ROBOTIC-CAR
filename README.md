# ROBOTIC-CAR
##
# 🚗 Obstacle Detecting Car Bot

An autonomous car bot that detects obstacles in its path and avoids collisions using sensors and microcontroller-based logic.

---

## 📌 Project Overview
This project demonstrates a smart robotic car capable of navigating its environment by detecting obstacles in real-time. It uses ultrasonic sensors to measure distance and automatically changes direction to avoid collisions.

---

## 🎯 Objectives
- Build an autonomous navigation system
- Implement obstacle detection using sensors
- Demonstrate real-time decision making in robotics
- Create a low-cost and efficient smart vehicle prototype

---

## ⚙️ Features
- Automatic obstacle detection
- Real-time distance measurement
- Self-navigation (forward, stop, turn)
- Compact and cost-effective design

---

## 🛠️ Components Used
- Microcontroller (Arduino / ESP32)
- Ultrasonic Sensor (HC-SR04)
- Motor Driver (L298N)
- DC Motors & Wheels
- Chassis
- Power Supply (Battery)
- Jumper Wires

---

## 🧠 Working Principle
1. Ultrasonic sensor emits sound waves
2. Waves reflect back after hitting an obstacle
3. Distance is calculated using time delay
4. If obstacle is too close:
   - Car stops
   - Changes direction
   - Continues moving
